A **commercial license** is available for the cases where AGPL-3.0 doesn't fit.

## When you need a commercial license

The AGPL is copyleft with a **network clause**: if you run a **modified**
version of HTMLRadar as a network service, you must offer the complete
corresponding source of your modified version to that service's users.
Combining AGPL code with proprietary code generally places the combined work
under the AGPL as well.

A commercial license removes those obligations. You likely want one if you plan
to:

- Run a **hosted / SaaS service** built on a modified HTMLRadar **without**
  publishing your modifications;
- **Embed** HTMLRadar or its tracker inside a **closed-source** product;
- Use it inside an organization whose policy **prohibits AGPL** software; or
- Otherwise use HTMLRadar in a way AGPL-3.0 would not permit.

If you only **self-host HTMLRadar as-is** — or self-host your own changes and
are happy to share them under the AGPL — you do **not** need a commercial
license. The AGPL already covers you, for free.
