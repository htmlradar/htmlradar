# Code of Conduct

HTMLRadar follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## TL;DR

- Be respectful.
- Assume good intent.
- No harassment, no personal attacks, no discrimination.
- Disagree on substance; don't disparage people.

## Enforcement

Concerns about behavior in the project (issues, PRs, discussions, or in any HTMLRadar community space) can be reported to `conduct@htmlradar.com`. All reports are handled confidentially. We take action proportional to the severity, ranging from a warning to a permanent ban.

## Scope

This applies to all project spaces — the repository, issue tracker, pull requests, discussions, and any official community channel.
