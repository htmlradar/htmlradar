# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in HTMLRadar, please **do not open a public GitHub issue.** Instead, email:

**`security@htmlradar.com`**

Please include:

- A description of the vulnerability
- Steps to reproduce (or a proof of concept)
- The version / commit SHA affected
- Your contact details so we can follow up

We will respond within 72 hours with an acknowledgement, and aim to ship a fix within 14 days for high-severity issues.

## Scope

The following are in scope:

- The hosted service at htmlradar.com
- The published tracker script at cdn.htmlradar.com/v1/tracker.js
- The code in this repository

Out of scope:

- Self-hosted instances run by third parties
- Forks or modified versions of HTMLRadar
- Social engineering, physical attacks, third-party services we depend on (Supabase, Cloudflare, Stripe)

## Disclosure

We follow coordinated disclosure: we'll work with you to fix the issue, then publish a security advisory once a fix is released. We credit reporters in the advisory unless you ask to remain anonymous.

## Out-of-band concerns

For non-security issues, use the GitHub issue tracker.
